SYNTHETIC EXPERIMENTS FOR THE AISTATS 2027 PAPER
Instructions for collaborators -- 23 September 2026
=====================================================================

WHAT THIS IS
------------
We measure how far a clean in-distribution point x has to be pushed along a
direction v before an OOD detector rejects it:

    alpha* = smallest alpha >= 0 with score(x + alpha*v) > t

where t is the detector's threshold, set so 5% of clean points are rejected
(tau = 0.05). The paper's claim: when the detector's reference set is
contaminated with a fraction pi of OOD points, alpha* drifts (bias) while the
resampling spread sigma_b stays small, so the detector is "confident and
wrong". The synthetic worlds let us check every step against a known answer.

Notation used below:
  n            reference size (points the detector is fitted on)
  pi           contamination fraction of the reference
  alpha*       first-rejection length along the path x + alpha*v
  sigma_b      SD of alpha* over B bootstrap resamples of the reference
  drift        Delta_alpha*(pi) = alpha*(pi) - alpha*(0), same probe, same v
  censored     no rejection up to alpha_max (leave blank, never fill in)

Worlds:
  G  Gaussian mean shift. P = N(0, Sigma), Q = N(Delta, Sigma),
     Sigma = diag(linspace(0.3, 3.0, d)), Delta scaled so
     Delta' Sigma^-1 Delta = sep^2. Default d = 20, sep = 3.
  S  First moment silent: the pool mean equals the reference mean, so the
     mean-difference direction has nothing to find. Two variants,
     S1 (symmetric clusters) and S2 (covariance only). To be built:
     task BUILD-S.
  M  Mixture of C caps on the unit sphere; Q is one extra cap. Paths
     are geodesics. To be built: tasks BUILD-M and BUILD-GEO.

2. THE CODE
-----------
  src/data/synth.py   make_world(d, sep, seed) -> dict(mu, Sigma, Delta, Sinv)
                      draw(world, n, pi, rng) -> (X, z); z=True means from Q
                      splits(world, rng, n_ref, n_calib, n_probe, n_dev,
                             n_oracle, n_contam, pi_dev) -> dict of arrays
  detectors.py        Maha, KNN(k), Linear(contaminant), Spectral
                      (Spectral is being replaced: task BUILD-SPECTRAL)
                      calibrate(det, D, calib, quantile=0.95) -> (det, t)
                          fit on D, threshold from clean calib split
                          ("protocol A")
                      calibrate_on_pool(det, D) -> (det, t)
                          threshold from D's own scores ("protocol B")
  paths.py            first_rejection(score_fn, t, x, v, alphas,
                                      refine_steps=30)
                          -> (alpha_star or None, censored, n_recross)
                      random_dirs(x, m, rng) -> m random unit vectors
  analytic.py         alpha_star_maha(x, v, mu, Sigma, t)  exact alpha*
                      alpha_star_maha_contaminated(x, v, world, pi, protocol)
                          population prediction under contamination
  run_walker.py       First check (A1.1, A1.2, A1.4, A2.1 at one setting).
                      Flags: --d --sep --grid --n-ref --pi-dev --seed --output

Splits (all independent draws):
  ref     clean P, n points. The detector is fitted on this.
  calib   clean P, 2000. Sets the threshold t.
  probe   clean P, 200. Starting points x.
  dev     mixture, 2000, fraction pi_dev from Q. Used ONLY to estimate the
          direction v_hat = unit(mean(dev) - mean(ref)). Never refit on it.
  oracle  clean P, 50000. For targets and rate checks.
  contam  pure Q, 2000. Mixed into ref to make the contaminated reference.

Rules (please keep these everywhere):
  - Never use the labels z for fitting or for choosing v. Analysis only.
  - Rejection is score > t, strictly.
  - A probe already rejected at alpha = 0 gets alpha* = 0 (not censored).
  - Censored alpha* is stored as blank/NaN, never as alpha_max.
  - Worlds G and S: straight paths x + alpha*v, v a Euclidean unit
    vector; do not project or renormalise points along the path.
  - World M: geodesic paths only (BUILD-GEO); alpha is an angle in
    radians and alpha_max <= pi.
  - Estimate the direction once from dev and keep it fixed across pi.
  - World seed 0 and data seed 1 unless the task says otherwise. Every
    script writes its settings and seeds into its summary.json.

BUILD-SPECTRAL  Replace the spectral detector            (before A6.1)
---------------------------------------------------------------------
Why: the paper defines the spectral score on a normalised Laplacian of a
cosine-weighted kNN graph. The current detectors.Spectral uses an
unnormalised RBF Laplacian, so its results would not speak for the
paper's claims (the conductance/Cheeger argument is about the
normalised operator).
What to change in detectors.py (class Spectral):
  1. Graph: kNN on cosine similarity, k = 10 (constructor argument).
     Symmetrise by UNION: i~j if i is in j's k nearest or j in i's.
  2. Weights: A_ij = max(cos(x_i, x_j), 0) on edges, 0 elsewhere,
     A_ii = 0.
  3. Operator: L = I - D^{-1/2} A D^{-1/2}, D = diag(A 1).
  4. Insertion of a query x: x connects to its k nearest reference
     points (cosine). Reference-reference edges stay fixed. Recompute the
     degree of x AND of the k reference nodes it touches, then rebuild
     only the rows/columns of L that change. Dense eigh is fine.
  5. Keep score_signed = lambda_2(augmented) - lambda_2(reference) and
     score = |score_signed|. Delta-lambda_2 is an eigenvalue difference
     and has no sign ambiguity.
  6. Fiedler vector sign: any quantity built from the Fiedler VECTOR
     (A9.2 realignment cosine, the new node's Fiedler entry if you log
     it along a path) must be sign-aligned against one fixed reference
     vector (the Fiedler vector of the pi = 0 reference): flip if the dot
     product is negative. Use the same alignment everywhere -- inside
     Spectral and in the analysis -- so signs do not flip between
     path steps or resamples.
  7. Keep the old operator behind a flag, Spectral(operator="rbf"),
     default operator="normalized_cosine". It is used for exactly one
     comparison run (in A9.1), then removed.
Check before use:
  - Unit test: two well-separated caps built by hand in the test (100
    points each around two orthogonal unit vectors, kappa = 0.05,
    normalised; world M is not needed): the Fiedler vector splits them (|cos| with the centred cap indicator > 0.9).
  - Unit test: inserting a copy of a reference point changes lambda_2
    by less than inserting a point far from all caps.
  - Update the Spectral tests in tests/test_synthetic.py to match.
  - State in NOTES.txt: k, union symmetrisation, clipped cosine weights.

  make_world_symmetric(d=20, sep=3.0, seed=0)
      S1. P = N(0, Sigma). Q = 1/2 N(+Delta, Sigma) + 1/2 N(-Delta, Sigma).
      Returns G's dict keys plus variant="S1".
  make_world_covshift(d=20, s2_factor=4.0, seed=0)
      S2. P = N(0, Sigma). Q = N(0, Sigma + s2 * u u').

      Returns G's dict keys plus variant="S2", u, s2.
  draw(world, n, pi, rng) -> (X, z), same signature as G.
      S1: each Q point gets its sign +/-Delta from a fair coin.
      S2: Q points drawn from the inflated covariance.
  splits: reuse G's splits (it only calls draw); if it cannot take the
  new draw, copy it into synth_s.py unchanged apart from draw.

  - Pool mean equals reference mean: with n = 200000 and pi = 0.3,
    |mean(pool)| < 0.02 in every coordinate, both variants.
  - Pool covariance: Sigma + pi Delta Delta' (S1), Sigma + pi s2 u u'
    (S2), to within 3% in Frobenius norm at n = 200000.

A7.5  Drift and spread along the repaired axis (after A7.3)
---------------------------------------------------------------------
S1 only. Mahalanobis, v = v_2 from A7.3, same pi grid and protocol as
A4.1/A4.2. Analytic overlay: the contaminated fit has mean 0 and
covariance Sigma + pi Delta Delta' (G's formula without the mean shift).
Compute alpha* with analytic.alpha_star_maha(x, v, 0, Sigma + pi
Delta Delta', t_pi), where t_pi is the population threshold of the
contaminated fit. In whitened coordinates the score is
chi2(d-1) + (Z + offset)^2 / lam with lam = 1 + pi * sep^2, so:
    from scipy.optimize import brentq
    from analytic import _component_cdf
    lam = 1 + pi * sep**2
    # protocol A: clean P scores only (offset 0)
    t_A = brentq(lambda t: _component_cdf(t, d, lam, 0.0) - 0.95, 1, 400)
    # protocol B: pool scores; Q at +/-Delta has offset sep (symmetric)
    t_B = brentq(lambda t: (1 - pi) * _component_cdf(t, d, lam, 0.0)
                 + pi * _component_cdf(t, d, lam, sep) - 0.95, 1, 400)
Check (d = 20, sep = 3; verified by simulation with 400000 points):
    pi = 0.1: t_A = 30.738, t_B = 31.674
    pi = 0.3: t_A = 30.431, t_B = 31.423
At pi = 0 both equal chi2.ppf(0.95, 20) = 31.410.

New file synth_m.py.
  make_world_sphere(d=20, C=3, kappa=0.15, theta_min=60, theta_Q=45,

    Centres mu_1..mu_C: random unit vectors in R^d; redraw until every

  make_world_sphere_spread(...): A8.3 variant. Q = P's own clusters with
    kappa multiplied by 2 (same centres, wider caps).
  draw(world, n, pi, rng) -> (X, z, c)
    ID point: pick cluster c uniformly, x = mu_c + kappa * N(0, I),
    then x <- x / ||x||. Q point: same around mu_Q (c = -1).
    z and c are for analysis only.
Points per cap, not n, are fixed: 100 per cap, so n = 300 for C = 3
and n = 1000 for C = 10. Run C = 3 first; C = 10 only after all C = 3

6. WHEN A CHECK FAILS
--------------------
Do not move past a failing validation check. Work through the list,
fix, rerun, and write what you found in NOTES.txt.

  A1.1 walker error > one grid step for more than 1% of probes:
    - The alphas grid must start at 0 and strictly increase.
    - Compare against the FITTED detector: pass det.mu and det.Sigma
      (not det.precision, not the population values) to
      alpha_star_maha, and the same t used by first_rejection.
    - With refine_steps=0, the walked value is the first grid point
      past the boundary, so the error is in [0, step), never negative.
  A2.1 curves do not collapse against pi_dev * n_dev:
    - ref and dev must be independent draws (different rng state).
    - ref must be clean (pi = 0); the direction uses no labels.
    - Use 50 redraws of dev with ref FIXED.
  A4.1 walked drift disagrees with the prediction:
    - Pass the world as a tuple (mu, Sigma, Delta) to
      alpha_star_maha_contaminated.
    - The prediction uses the ACTUAL contamination fraction of the pool
      (added / (n + added)), not the requested pi; use it.
    - Protocol A thresholds on the clean calib split; B on the pool.
    - Rerun with seeds 1..20. If mean drift still disagrees by more than
      2 standard errors, record it as a result in NOTES.txt (with the
      size of the gap per pi) and continue.
  A5.1 coverage at pi = 0 outside 0.87-0.93:
    - The bootstrap resamples ref only; calib, probes and v stay fixed.
    - The target uses the population mu, Sigma and chi2.ppf(0.95, d).
    - Use empirical percentiles (5th and 95th) of the B values of alpha*.
    - If it is still off, record the coverage as a result and continue
      to A5.2; the report must say coverage at pi = 0 was not nominal.

Changing shared code:
  - BUILD-SPECTRAL and BUILD-GEO tell you exactly what to change in
    detectors.py and paths.py; make those changes.
  - For anything else, do not change the behaviour of existing
    functions in src/, detectors.py, paths.py or analytic.py. Add a new
    function or an optional argument whose default keeps the old
    behaviour, and list every such change in results/CHANGES.txt.
